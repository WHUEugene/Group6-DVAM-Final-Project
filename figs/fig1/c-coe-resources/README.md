# Fig 1c - Reduction in Training Resources

This panel is a bubble chart comparing data size vs training tokens for three models. Bubble size scales with combined resource usage.

Files
- `plot.py` generates the figure.
- `fig_c_coe_resources.png` is the output image.

Run
```bash
python plot.py
```

Notes
- Data are embedded in the script.
- The legend is positioned to avoid overlapping the bubbles.
