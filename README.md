# Group 6 - Data Visualization and Analysis Methods Final Project

This repository contains the final project figures split into one file per subfigure, each with its own README. The PNG outputs are included and can be regenerated by running the corresponding `plot.py`.

Group
- Group number: 6

Structure
- `figs/fig1/` contains Fig 1 subpanels (a, b, c).
- `figs/fig5/` contains Fig 5 subpanels (a through l).
- Original scripts are kept in `fig_1_a_evo.py` and `data_vis/` for reference.

Quick start
```bash
# Example: regenerate Fig 1a
python figs/fig1/a-development/plot.py

# Example: regenerate Fig 5e
python figs/fig5/e-threshold-comparison/plot.py
```

Dependencies
- Python 3.9+
- numpy
- matplotlib
- matplotlib-venn (for Venn diagrams in Fig 5j/k/l)

Documentation
- Each subfigure folder includes a `README.md` describing the plot and how to run it.
